# M. PABON BMIN5030 Final Project

# Influenza Vaccine Response in FluPRINT

This project explores how age, baseline immune measurements, and recorded influenza vaccination history relate to high versus low antibody response after seasonal influenza vaccination. It uses the FluPRINT dataset and accounts for differences between contributing studies. A broader exploratory analysis examines 50 baseline immune markers with correction for multiple comparisons.
